Atur Sesi FASIH

Sesi ini disimpan di server dan dipakai tombol “Perbarui”. Tidak perlu mengubah file di server.

  1. Buka FASIH dan login di browser:

  2. Tekan F12 → tab Network → muat ulang halaman.
  3. Klik permintaan mana pun → Request Headers → cari Cookie.
  4. Klik kanan nilainya → Copy value, lalu tempel di kotak bawah.
